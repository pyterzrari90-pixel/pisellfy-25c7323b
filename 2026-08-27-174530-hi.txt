  ## Problème à résoudre                                                        
                                                                                
  Actuellement, rien n'empêche un utilisateur A de modifier ou supprimer un     
  produit créé                                                                  
  par un utilisateur B. Il faut ajouter une vérification de propriété           
  (ownership) partout                                                           
  où un produit peut être créé, modifié ou supprimé.                            
                                                                                
  Ce prompt part du principe que la persistance partagée (base de données + API 
  Routes,

  ce n'est                                                                      
  pas encore fait, dis-le-moi avant de commencer.                               
                                                                                
  ## Ta mission                                                                 
                                                                                
  ### 1. Modèle de données

  propriétaire,                                                                 
    par exemple `sellerId: string` (le lier à l'identifiant Pi Pioneer de       
  l'utilisateur                                                                 
    connecté, récupéré via `lib/pi-sdk.ts` → `getUser()`, sans modifier ce

  - Si ce champ n'existe pas encore, ajoute-le et adapte `lib/mock-data.ts` en

  équivalent) :                                                                 
  - Pour un `PUT`/`PATCH` (modification) : vérifie que `sellerId` du produit    
  correspond

  une erreur

  clairement liée aux modifications actuelles.                                  
                                                                                
  ---                                                                           
                                                                                
  ## 7. Préparer le commit                                                      
                                                                                
  Avant de faire `git add`, affiche :                                           
                                                                                
  ```bash                                                                       
  git status                                                                    
  git diff --stat                                                               
  ```                                                                           
                                                                                
  Puis ajoute les modifications :                                               
                                                                                
  ```bash                                                                       
  git add .                                                                     
  ```                                                                           
                                                                                
  Vérifie impérativement ce qui sera envoyé :                                   
                                                                                
  ```bash                                                                       
  git diff --cached --stat                                                      
  ```                                                                           
                                                                                
  Si un fichier sensible apparaît, retire-le du staging avant de continuer.     
                                                                                
  ---                                                                           
                                                                                
  ## 8. Créer le commit                                                         
                                                                                
  Crée un commit avec un message descriptif.                                    
                                                                                
  Par exemple :                                                                 
                                                                                
  ```bash                                                                       
  git commit -m "Update PiSellfy application"                                   
  ```                                                                           
                                                                                
  Si tu peux identifier précisément les fonctionnalités modifiées, utilise un   
  message plus précis.                                                          
                                                                                
  ---                                                                           
                                                                                
  ## 9. Envoyer vers GitHub                                                     
                                                                                
  Une fois toutes les vérifications terminées :                                 
                                                                                
  ```bash                                                                       
  git push origin main                                                          
  ```                                                                           
                                                                                
  ⚠️ INTERDICTION d'utiliser :                                                  
                                                                                
  ```bash                                                                       
  git push --force                                                              
  ```                                                                           
                                                                                
  ou :                                                                          
                                                                                
  ```bash                                                                       
  git push -f                                                                   
  ```                                                                           
                                                                                
  ou :                                                                          
                                                                                
  ```bash                                                                       
  git reset --hard                                                              
  ```
